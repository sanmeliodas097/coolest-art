A Python program that writes one piece of art to /output/entry.png — a colossal blue whale swimming through a dusky city sky between skyscrapers, lit by warm golden windows. The art is shipped as entry.png beside the program, and the program copies it byte-for-byte, so every run is identical with no network access.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
